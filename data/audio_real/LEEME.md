# Grabaciones reales (opcional)

Coloque aquí sus grabaciones propias en formato `.wav` con el nombre
`instrumento_nota_toma.wav` (por ejemplo `guitarra_A4_01.wav`).

Instrucciones completas de grabación: [`docs/protocolo_grabacion.md`](../../docs/protocolo_grabacion.md)

Para analizarlas:

```bash
python -m src.main --audio-dir data/audio_real
```
